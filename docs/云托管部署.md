# 微信云托管（CloudBase Run）部署步骤

基于本项目已完成的改造，按下面顺序执行即可。云托管用 `callContainer` 调用，**无需域名、无需 ICP 备案**。

---

## 1）开通云托管环境

1. 打开 [cloud.weixin.qq.com](https://cloud.weixin.qq.com)（或 mp 后台 → 云开发）→ 开通。
2. 创建环境，记下**环境 ID**（形如 `island-1a2b3c`）。
3. 小程序基础库 ≥ **2.21.1**（本项目 3.5.0 ✅）。

## 2）创建云数据库（PostgreSQL）

1. 云开发控制台 → 数据库 → 新建 PostgreSQL 实例（或云托管 → 云数据库）。
2. 拿到连接串，例如：
   ```
   postgresql://user:pass@host:5432/island?schema=public
   ```
3. 记下来，第 4 步填到环境变量 `DATABASE_URL`。

## 3）前端填云托管配置（`miniprogram/app.js`）

```js
cloudEnv: 'island-1a2b3c',        // ← 第 1 步的环境 ID
serviceName: 'island-server',     // ← 第 4 步创建的服务名，保持一致
forceCloud: false,                // 想让「真机调试」也走云托管就设 true
```

代码已按环境自动判定：`trial`/`release` 自动走云托管；`develop` 仍走局域网（`LAN_BASE`），互不影响。

## 4）部署后端服务

**方式 A：云开发 CLI**
```bash
npm i -g @cloudbase/cli
tcb login
cd server
tcb cloudrun deploy
```

**方式 B：控制台**
云托管 → 服务 → 新建服务 → 选择「本地代码 / Dockerfile」→ 上传 `server/` 目录 → 构建部署。

**服务环境变量（必填）**

| 变量 | 值 |
|---|---|
| `STORE` | `prisma` |
| `DATABASE_URL` | 第 2 步的连接串 |
| `MOCK_AUTH` | `true`（先用 mock 登录）；要真实登录设 `false` 并填 `WX_SECRET` |
| `MOCK_AI` | `true`（先用 mock AI）；接真实大模型设 `false` |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | `MOCK_AI=false` 时填 |

健康检查路径填 `/api/health`（项目已自带）。

> 容器启动时会检测 `STORE=prisma` 并自动执行 `prisma migrate deploy`（迁移 SQL 已在 `server/prisma/migrations/`）。

## 5）上传小程序 → 体验版验证

1. 开发者工具 **上传**。
2. mp 后台 → 管理 → 版本管理 → 设为**体验版** → 添加体验成员 → 扫码测试。
3. **无需**在 mp 后台配置 `request 合法域名` / `socket 合法域名`（云托管免域名）。

## 6）发布上线

- 云托管免域名备案，但**小程序备案仍需做**：mp 后台 → 设置 → 小程序备案。
- 备案通过 → 提交审核 → 发布。

## 已完成的改造（代码侧）

| 文件 | 改动 |
|---|---|
| `miniprogram/app.js` | `wx.cloud.init` + `cloudEnv`/`serviceName`/`forceCloud`，按环境自动切换 |
| `miniprogram/utils/request.js` | 云托管走 `wx.cloud.callContainer`，否则仍走 `wx.request` |
| `miniprogram/utils/ws.js` | 云托管走 `wx.cloud.connectContainer`；统一返回 `send/close` 句柄，并修复「主动关闭后仍重连」的泄漏 |
| `server/Dockerfile` | 构建 `prisma generate` + `npm run build`；`STORE=prisma` 时启动前自动迁移 |
| `server/prisma/migrations/` | 已生成初始迁移 SQL（`prisma migrate deploy` 可直接用） |

---

## 必须注意的限制

| 限制 | 说明 |
|---|---|
| **必须用 `callContainer`** | 若用 `wx.request` 打云托管公网域名，仍受 `request 合法域名` 限制，仍需备案 |
| 超时 ≤ 15s | `callContainer` 上限，AI 慢回复需优化 |
| 请求体 ≤ 100K | 图片用云存储，别走请求体 |
| iOS 高性能+ 模式 | `connectContainer` 读不到 `x-wx-openid` |
| 冷启动 | 可在控制台设置实例常驻 |
| 不支持 Docker Compose | 数据库要用独立云数据库 |
