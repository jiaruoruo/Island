# 部署上线实操（让手机能直接操作）

微信小程序的「真机/上线」有一条绕不开的规则：**手机上发往后端的请求，正式版/体验版必须走 HTTPS 且域名在微信后台白名单内**；只有「开发者工具」和「真机调试」可以临时跳过校验。

本项目已做：
- 前端 `app.js` 按运行环境自动切换后端地址（`develop`=局域网；`trial/release`=线上 HTTPS，域名在 `app.js` 的 `PROD_BASE` 填）。
- 服务端已支持 `npm run build` 产出 `dist/`，并附 `Dockerfile` / `ecosystem.config.js`(PM2) / `.env.example`。

---

## 路线 A：真机调试（最快，今天就能在手机上用，零成本）

适合「我现在就要在手机上点点看」，代价是：手机和电脑必须同一 WiFi，电脑上的服务要一直开着。

1. 电脑起后端：
   ```bash
   cd server && npm install && npx prisma generate && npm run dev
   ```
2. 查电脑局域网 IP：`ipconfig | findstr IPv4`（如 `192.168.1.23`）。
3. 改 `miniprogram/app.js` 里的 `LAN_BASE` 为 `http://192.168.1.23:3000`。
4. **放行防火墙**（PowerShell 管理员）：
   ```powershell
   New-NetFirewallRule -DisplayName "Island-3000" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
   ```
5. 微信开发者工具顶部点 **真机调试** → 手机扫码 → 手机即可运行，电脑端可看日志/断点。

> 因为 `project.config.json` 已 `urlCheck:false`，真机调试下 `http://局域网IP` 可用。

## 路线 B：体验版 / 正式版（手机随地可用，需服务器+域名）

### 1）准备后端可运行包（任选其一）

**Docker（推荐）**
```bash
cd server
docker build -t island-server .
docker run -d -p 3000:3000 --name island island-server
```

**PM2（需先装 Node）**
```bash
cd server
npm install && npx prisma generate && npm run build
npm i -g pm2
pm2 start ecosystem.config.js
```

生产环境变量：复制 `.env.example` 为 `.env` 填写。`STORE=memory` 开箱即跑（重启清空数据）；要持久化改 `prisma` 并配 `DATABASE_URL` + `docker compose up -d` + `npm run db:migrate`。

### 2）准备域名 + HTTPS

- 买域名（如 `api.yourdomain.com`），解析到服务器 IP。
- 申请 HTTPS 证书（云厂商免费证书 / Let's Encrypt），用 Nginx 反代到 `localhost:3000`。
- 改 `miniprogram/app.js` 的 `PROD_BASE` 为 `https://api.yourdomain.com`。

> ⚠️ **ICP 备案**：在中国大陆，把域名加入微信「request 合法域名」要求域名已完成 ICP 备案。备案一般需 1–2 周，请尽早办理。

### 3）微信公众平台配置

- 登录 mp.weixin.qq.com → 开发 → 开发管理 → 开发设置 → **服务器域名**
  - `request 合法域名`：`https://api.yourdomain.com`
  - `socket 合法域名`：`wss://api.yourdomain.com`
- 开发 → 开发管理 → 接口设置：按需开通 **camera（扫一扫）**、**writePhotosAlbum（保存相册）**。
- 设置 → 服务内容/用户隐私保护指引：声明 **摄像头、相册（写入）**，否则审核驳回。

### 4）上传 → 体验版 → 审核 → 发布

1. 开发者工具顶部 **上传**（填版本号 + 备注）。
2. mp 后台 → 管理 → 版本管理 → 把刚上传的设为 **体验版** → 添加体验成员 → 扫体验版码即可随地测试（免审核）。
3. 确认无误后 **提交审核** → 审核通过 → **发布**。

## 真机才能验证的功能（模拟器无效）

- 扫一扫 `wx.scanCode`（调相机）
- 邀请微信好友 `open-type="share"`（拉起好友选择页）
- 保存二维码到相册 `wx.saveImageToPhotosAlbum`
- 微信登录（需 `MOCK_AUTH=false` + 填 `WX_SECRET`）

> 想接真实大模型：`.env` 设 `MOCK_AI=false` + `LLM_BASE_URL/LLM_API_KEY/LLM_MODEL`，无需改代码。详见 `联调与上线指引.md`。
