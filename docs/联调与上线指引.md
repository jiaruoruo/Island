# 联调与上线指引

从「本地 Mock 跑通」到「接入真实大模型 + 小程序真机/上线」的完整步骤。

---

## 一、接入真实大模型（LLM）

后端采用 **OpenAI 兼容客户端**，改 `.env` 即可切换任意国产大模型。

### 1. 各平台 OpenAI 兼容端点（参考）

| 平台 | `LLM_BASE_URL` | 常用 `LLM_MODEL` |
|------|----------------|------------------|
| 火山方舟·豆包 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-1-5-pro-32k-250115`（或用推理接入点 ID） |
| 腾讯混元 | `https://api.hunyuan.cloud.tencent.com/v1` | `hunyuan-lite` / `hunyuan-pro` |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-turbo` |
| Kimi(月之暗面) | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |

### 2. 配置 `.env`

```ini
STORE=prisma            # 或 memory（无数据库时仍可用真实 LLM）
MOCK_AI=false
LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_API_KEY=你的密钥
LLM_MODEL=doubao-1-5-pro-32k-250115
EMBED_MODEL=你的向量模型   # 如平台不支持 embedding，会自动回退到本地特征哈希
```

> 说明：`embed()` 在 embedding API 不可用/出错时会自动回退到本地特征哈希（`feature-hash`），因此即使所选平台没有向量模型，记忆检索仍可工作（精度略降）。

### 3. 重启后端

```bash
cd server && npm run dev
```

## 二、PostgreSQL + 迁移 + seed

### 1. 起数据库

```bash
docker compose up -d
```

### 2. 迁移并生成客户端

```bash
cd server
npm run prisma:generate
npm run db:migrate        # 首次会生成 migrations/ 并建表
```

### 3. 灌入演示数据

```bash
npm run db:seed
# 输出：coupleId=seed_couple, userIdA=seed_a, userIdB=seed_b
```

### 4. 用 Prisma 存储启动

`.env` 设 `STORE=prisma` 后 `npm run dev`。

## 三、小程序真机 / 上线

### 1. 本地开发（开发者工具）

- 导入 `miniprogram/` 目录，AppID 用 `touristappid`（游客模式）或你的 AppID。
- 勾选「详情 → 本地设置 → **不校验合法域名**」（仅本地 `localhost` 需要）。

### 2. 后端地址配置

编辑 `miniprogram/app.js`：

```js
globalData: {
  baseUrl: 'https://你的域名',   // 真机必须 HTTPS
  wsBase: 'wss://你的域名',      // WebSocket 必须 wss
  ...
}
```

### 3. 真机与上线必做清单

| 项 | 说明 |
|----|------|
| 微信登录 | `MOCK_AUTH=false` + 填 `WX_APPID`/`WX_SECRET`（`code2Session`） |
| 域名白名单 | 小程序后台配置 **request 合法域名** 与 **socket 合法域名**，必须 HTTPS/WSS |
| 实名年龄核验 | 接第三方实名 API，替换 `middleware/auth.ts` 中 Mock 逻辑（`REAL_ID_VERIFY=true`） |
| 文本审核 | 接内容安全 API，替换 `compliance/moderate.ts` 的 `externalModerate` |
| 微信支付 | 订阅内购需商户号，替换 `routes/subscription.ts` 的 Mock 流程 |
| 订阅消息 | 纪念日/约定提醒接入小程序订阅消息推送 |
| 隐私合规 | 小程序后台配置《用户隐私保护指引》，声明收集的手机号、聊天内容等 |

### 4. 合规红线（上线前必须满足）

- **禁止向未成年人提供虚拟亲密关系服务**（《人工智能拟人化互动服务管理暂行办法》）。
- 前端欢迎页已做年龄确认 → 未成年人进入 `minorMode`（禁 AI 亲密互动 + 禁付费），上线需接入**真实实名核验**兜底。
- 双人共享记忆需双方授权；解散小岛可删除数据。

## 四、常见问题

| 问题 | 解决 |
|------|------|
| `npm run dev` 起不来 | 确认 `npm install` 完成；Node ≥ 18 |
| Prisma 报连接失败 | 先 `docker compose up -d`，确认 `.env` 的 `DATABASE_URL` |
| 真机请求失败 | 域名必须 HTTPS 且在后台白名单内；关闭「不校验合法域名」仅对本地有效 |
| AI 无记忆/回复异常 | 检查 `LLM_API_KEY`；embedding 不可用会自动回退，属正常 |
| 想换大模型 | 改 `LLM_BASE_URL`/`LLM_MODEL` 即可，无需改代码 |
